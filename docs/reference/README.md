# Technical references

These reports were extracted from the former branch as engineering background. They are not executable specifications and may describe historical candidate comparisons. The active values live in `verification_modeling/coil.py` and `receiver_design/`.

- `afe-evaluation.md` covers amplifier noise, tuned inputs, blanking, and gain staging.
- `frequency-estimation.md` derives the estimator bounds and compares algorithms.
- `mcu-evaluation.md` covers host testing, target choices, timing, and clock error.
- `circuit-formats.md` compares circuit representations and EDA interchange options.
