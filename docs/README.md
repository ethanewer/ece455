# Documentation

- [`design.md`](design.md) describes the boards, amplifier, firmware, and coils, and lists open issues.
- [`verification-plan.md`](verification-plan.md) lists the bench measurements that replace modeled values.
- [`simulation/`](simulation/README.md) is generated by `make sim`: amplifier gain, noise, the FID at the ADC, and tuning-bank switch settings.
- [`breadboard/`](breadboard/README.md) is generated by `make breadboard`: the off-board amplifier on an 830-point breadboard, hole by hole.
- [`datasheets/`](datasheets/) has the ADS1256 datasheet.
- [`references/`](references/) has papers, tutorials, and earlier teams' magnetometer projects. They are background, not requirements.

Do not edit the generated folders by hand; change the design file or the generator in `util/` and regenerate.
